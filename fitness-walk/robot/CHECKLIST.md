# 檢查清單：仿生健身女性（背面）

參考圖：使用者提供的角色設定圖，取「背面」那一格量測。以下比例都是佔**站姿全高 H**（頭髮頂到鞋底）的比例。

| 部位 | 參考圖寬度 / H | 位置（距頭頂 / H） |
|---|---|---|
| 頭髮最寬 | 0.135 | 0.12 |
| 頭髮下緣（鮑伯頭） | — | 0.17 |
| 肩寬（含三角肌） | 0.26 | 0.25 |
| 腰（最細處） | 0.14 | 0.33 |
| 臀腿最寬處 | 0.245 | 0.52 |
| 胯下 | — | 0.555 |
| 單邊大腿 | 0.108 | 0.58 |
| 膝 | 0.067 | 0.72 |
| 小腿最粗 | 0.075 | 0.80 |
| 腳踝上方 | 0.044 | 0.88 |
| 深色像素佔比（luma < 80） | 0.13 | — |

1. **輪廓與視角**：背面站姿，雙臂微微離開身體。上表每一項比例和參考圖相差 0.02 以內，腰臀比約 0.57，肩寬略大於臀寬（倒三角，健身體態）。
2. **招牌特徵：背部肌群**。用分開的白色曲面板表現：斜方肌、肩胛（棘下肌）、背闊肌 V 型、豎脊肌兩條。V 型輪廓要一眼看得出來。**絕對不要**做成一整片光滑背殼。
3. **脊椎外露**：沿中線露出深色椎節（至少 12 節）和一條綠色細線，從腰帶上方延伸到頸部。
4. **鮑伯頭**：深色（近黑棕）薄片一層一層疊出髮絲感，下緣切齊在下巴高度（0.17H），微微外翻。**絕對不要**做成一顆光滑的球。
5. **運動內衣**：深灰色 racerback。背面中央一片，往上分成 Y 字兩條肩帶，下緣是一圈底帶（約 0.30H）。左右肩胛的白板外露。
6. **緊身褲**：沙色（參考圖的裸膚色系）曲面板。高腰到肚臍高度（約 0.35H），要有一條看得出來的腰帶線。從臀部包到腳踝。**和白色上身板明顯區分。**
7. **曲面板分三種大小、之間留縫**：縫隙露出深色機構（伺服、連桿、管線）。每段肢體至少 3 片板。
8. **力量感來源**：小腿後面的阿基里斯腱液壓缸、膝後的連桿、肩關節和髖關節的伺服環都露出來。關節環用綠色細線。
9. **臀部與腿型**：運動員體型。臀部飽滿但不誇張，寬度照第 1 條的數字。大腿外側要有股外側肌的弧線，小腿要有腓腸肌兩個頭。
10. **白色運動鞋**：白殼加深色鞋底。
11. **綠色只當細線**：關節環、脊椎線、少數板緣。不要散落的綠點。
12. **深色佔比**：在人物框內至少達到參考圖的 0.8（≥ 0.10）。
