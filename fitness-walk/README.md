# 力與美 · 純程式生成的健身女性走路動畫

這個資料夾裡沒有 3D 模型檔、沒有貼圖、沒有音檔，畫面和聲音全部由程式產生。

| 檔案 | 用途 |
|---|---|
| `index.html` | 單一網頁。用瀏覽器打開就能即時播放，按左下角按鈕會連聲音一起播 |
| `render.mjs` | 用無頭 Chromium 逐格渲染 300 張 (10 秒 × 30fps)，再用 ffmpeg 合成 MP4 |
| `out/fitness-walk.mp4` | 渲染結果 (不進 git) |

```bash
node render.mjs 540 960 30      # 寬 高 fps
```

## 做法：四層

1. **骨架與步態 (JS)**：髖、膝、腳掌各給 9 個關鍵影格 (腳跟著地 → 支撐期 → 蹬地 → 擺盪期)，用週期 Hermite 曲線內插。骨盆會旋轉、側傾 (擺盪側下沉) 並左右移動重心，肩膀反向旋轉，手臂跟對側腿同步擺動。用正向運動學 (FK) 算出每個關節的位置。
2. **腳不滑步**：每一毫秒找出最低的接觸點 (腳跟或腳尖)，讓它貼齊地面並保持不動，用這個條件反推身體的前進量和上下起伏。所以前進速度、身體起伏、腳步聲的時間點都是算出來的，不是手調的。
3. **身體建模 (SDF)**：約 50 個圓錐膠囊和橢球，各自代表一塊肌群：斜方肌、背闊肌 V 型、棘下肌、豎脊肌、三角肌、三頭肌、股外側肌、膕旁肌、腓腸肌內外側頭……再用 smooth-min 融合成一個連續曲面。脊椎溝是用平滑減法挖出來的。運動內衣 (racerback)、高腰緊身褲的腰帶和接縫則是在 shader 裡依身體局部座標「畫」上去的。
4. **渲染 (GLSL ray marching)**：低角度逆光的晨光讓輪廓發亮，再加一盞左側的掠射主光把背肌的起伏照出來。另有軟陰影、AO、濕地面反射、遠方天際線、雲、路燈、ACES 色調映射和暗角。
5. **聲音 (Web Audio API)**：腳步聲 = 低頻正弦悶擊 + 帶通雜訊摩擦 + 腳尖離地的高頻輕刮，時間點直接取自第 2 步算出的觸地時刻。另外有低通雜訊做的遠方車流、正弦滑音做的鳥叫，以及慢慢推高濾波器的低頻五度和弦。輸出影片時用 OfflineAudioContext 離線渲染成 WAV。
